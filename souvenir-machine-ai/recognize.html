Sound Recognition AudioSet

Records a short clip and asks MIT's Audio Spectrogram Transformer, fine-tuned on Google's AudioSet, to tag it. Originally built against Microsoft's BEATs — swapped after finding BEATs has no hosted API and is itself a fixed classifier, not zero-shot. See the README for the full story. Scores are against AudioSet's ~527 fixed categories, not free-typed labels.
